## 1. Філософія

Meridian побудовано навколо трьох правил, які усувають випадкові рішення й забезпечують передбачуваність інтерфейсу.

### 1.1 Одна форма для всіх контролів

Будь-який інтерактивний елемент — кнопка, поле, чекбокс, пункт меню — має **однаковий border-radius `8px`** (`--r-2`). Коло (`999px`) дозволено лише трьом об'єктам: аватару, перемикачу та значку-індикатору. Проміжних значень немає.

### 1.2 Стан — це шар, а не новий колір

Наведення, натиск і перетягування не вводять нових кольорових токенів. Натомість поверх елемента накладається напівпрозорий шар із `currentColor`:

| Стан | Opacity | Токен |
|------|---------|-------|
| Hover | 8% | `--st-hover: .08` |
| Press / Active | 13% | `--st-press: .13` |
| Drag | 18% | `--st-drag: .18` |

Один механізм працює однаково на будь-якому тлі — світлій кнопці, темному меню чи акцентній заливці.

### 1.3 Рух пояснює, а не прикрашає

Дозволено чотири тривалості й одна основна крива. Анімація інформує про зв'язок елементів (звідки з'явилося, куди зникло), а не «прикрашає». Усі анімації вимикаються за `prefers-reduced-motion`.

### 3.2 Маппінг рампи → семантичні токени

| Токен | Призначення | Light ← ramp[] | Dark ← ramp[] |
|-------|-------------|----------------|---------------|
| `--acc-bg` | Суцільна заливка кнопки | `[3]` | `[3]` |
| `--acc-bg-hover` | Hover суцільної | `[4]` | `[2]` |
| `--acc-fg` | Текст на суцільній заливці | `#ffffff` | `#ffffff` |
| `--acc-text` | Акцентний текст на тлі | `[4]` | `[2]` |
| `--acc-soft` | Тональна підкладка (вибір) | `[0]` (solid) | `rgba([2], .20)` |
| `--acc-soft-fg` | Текст на тональній підкладці | `[5]` | `[1]` |
| `--acc-ring` | Кільце фокуса | `rgba([3], .32)` | `rgba([2], .40)` |

> В темній темі `--acc-soft` — це **напівпрозорий** варіант (20% від ac-3), щоб тональна підкладка працювала на темних поверхнях без «вигорання».

### 3.3 Використання

- **`--acc-bg`** → primary-кнопка, бігунок, індикатор вкладки, progress bar
- **`--acc-soft` + `--acc-soft-fg`** → виділений пункт sidebar, активний badge, тональна кнопка
- **`--acc-text`** → текст-посилання, активний label, мітка фокуса поля
- **`--acc-ring`** → `box-shadow: 0 0 0 3px var(--acc-ring)` при `:focus-visible`

- **Курсив заборонений** — інформація виділяється вагою або кольором, не нахилом.

- Від'ємний tracking на великих кеглях (до −0.03em на Display) компенсує оптичне «розриджування».
- Числові дані завжди набираються `JetBrains Mono` з `tabular-nums`, щоб колонки не «стрибали».

## 6. Відступи

Базовий крок — **4px**. Дозволено лише 8 значень:

| Токен | Значення | Застосування |
|-------|----------|-------------|
| `--sp-1` | `4px` | Мінімальний зазор |
| `--sp-2` | `8px` | Gap між іконкою і текстом |
| `--sp-3` | `12px` | Внутрішній відступ toast, banner |
| `--sp-4` | `16px` | Внутрішній відступ картки, padding кнопки |
| `--sp-5` | `24px` | Gap секції, padding панелі |
| `--sp-6` | `32px` | Padding deco-stage |
| `--sp-7` | `48px` | Відступ між секціями документа |
| `--sp-8` | `64px` | Нижній padding документа, margin секції |

> Правило вкладеності: **внутрішній відступ контейнера завжди на один щабель менший за зовнішній.** Проміжні числа заборонені.

### Ключові розміри

| Елемент | Значення |
|---------|----------|
| Висота контрола (btn, input) | `34px` |
| Висота малого контрола | `28px` |
| Висота великого контрола | `42px` |
| Висота панелі вікна | `48px` |
| Висота системної смуги | `34px` |

## 7. Шкала форм

П'ять щаблів border-radius. Радіус визначається **роллю** елемента в ієрархії, а не його розміром:

| Токен | Значення | Роль | Приклади |
|-------|----------|------|----------|
| `--r-1` | `4px` | Мікроелемент | Тег, чип, badge, індикатор |
| `--r-2` | `8px` | **Контрол** | Кнопка, поле вводу, чекбокс, пункт меню |
| `--r-3` | `12px` | Контейнер | Картка, меню, вікно, datepicker |
| `--r-4` | `18px` | Оболонка | Системна панель, док |
| `--r-round` | `999px` | Коло | Аватар, перемикач (switch), badge-pill |

> Між щаблями **немає проміжних значень**. Кожен елемент належить рівно одному щаблю.

## 8. Шари стану

Реалізація через CSS pseudo-element `::before` з `background: currentColor`:

```css
.layer::before {
  content: ''; position: absolute; inset: 0; z-index: -1;
  background: currentColor; opacity: 0;
  transition: opacity var(--t-1) var(--e-io);
}
.layer:hover::before   { opacity: .08; }  /* --st-hover */
.layer:active::before  { opacity: .13; }  /* --st-press */
```

Цей механізм використовується в:
- `.btn` (усі варіанти)
- `.menu-item`
- `.wctl button` (кнопки вікна)
- `.topbar .tb-btn` (кнопки системної панелі)

| Токен | Тінь | Застосування |

| Токен | Стан | Light | Dark |
|-------|------|-------|------|
| `--el-win` | Активне | border `1px .07` + `6px 14px .10` + `26px 60px .22` | border `1px white .10` + `8px 16px .5` + `32px 68px .6` |

## 10. Рух (motion)

### 10.1 Тривалості

| Токен | Значення | Застосування |
|-------|----------|-------------|
| `--t-1` | `120ms` | Реакція контрола: шар стану, hover |
| `--t-2` | `200ms` | Зміна стану: розкриття меню, зміна кольору |
| `--t-3` | `320ms` | Розкриття: аккордеон, зміна геометрії вікна |
| `--t-4` | `420ms` | Сцена: поява вікна, огляд, launcher |

### 10.2 Криві

| Токен | Значення | Характер |
|-------|----------|----------|
| `--e-out` | `cubic-bezier(.2, 0, 0, 1)` | **Основна**: різкий старт, довгий довід |
| `--e-io` | `cubic-bezier(.4, 0, .2, 1)` | Симетрична: для фонових властивостей |
| `--e-over` | `cubic-bezier(.32, 1.28, .5, 1)` | Легкий **переліт**: перемикачі, масштаб |

### 10.3 Правила застосування

| Властивість | Тривалість | Крива |
|-------------|-----------|-------|
| `opacity` шару стану | `--t-1` | `--e-io` |
| `background`, `color`, `border-color` | `--t-2` | `--e-out` |
| `transform` (scale кнопки) | `--t-1` | `--e-out` |
| `transform` (hover підйом) | `--t-2` | `--e-over` |
| `grid-template-rows` (accordion) | `--t-3` | `--e-out` |
| Геометрія вікна (left, top, width, height) | `--t-3` | `--e-out` |
| Поява/зникнення вікна (transform+opacity) | `--t-4` | `--e-out` / `--e-io` |
| Фонові властивості (theme switch) | `--t-3` | `--e-io` |

## 11. Компоненти

### 11.1 Кнопки (Buttons)

Єдиний клас `.btn` з модифікаторами:

| Модифікатор | background | color | border | Додатково |
|-------------|-----------|-------|--------|-----------|
| *(base)* | `--fill-1` | `--fg-1` | transparent | — |
| `--primary` | `--acc-bg` | `--acc-fg` | — | `box-shadow: --el-1` → `--el-2` on hover |
| `--tonal` | `--acc-soft` | `--acc-soft-fg` | — | — |
| `--outline` | transparent | `--fg-1` | `--line-2` | border → `--fill-3` on hover |
| `--ghost` | transparent | `--fg-2` | — | → `--fg-1` on hover |
| `--danger` | `--danger-soft` | `--danger` | — | → `--danger` bg + `--view-bg` text on hover |

**Розміри:**

| Модифікатор | min-height | padding | font-size |
|-------------|-----------|---------|-----------|
| *(base)* | 34px | `0 16px` | 13.5px |
| `--sm` | 28px | `0 11px` | 12.5px |
| `--lg` | 42px | `0 22px` | 14.5px |
| `--icon` | 34px wide = 34px | `0` | — |

**Зчеплена група** (`.linked`): зовнішні кнопки мають `--r-2`, внутрішні — `--r-1`.

**Сегментований контрол** (`.segmented`): рухома підкладка (`.seg-thumb`) переміщується JS-ом. Активна кнопка отримує фон `--card-bg` з тінню `--el-1`.

### 11.2 Поля вводу (Fields)

| Елемент | Клас | Особливості |
|---------|------|-------------|
| Text input | `.input` | `min-height: 34px`, border `--line-2`, bg `--view-bg` |
| Textarea | `.textarea` | `min-height: 84px`, `resize: vertical` |
| Select | `select.input` | Custom chevron через `background-image` |
| Search | `.searchbar` > `.input` | Іконка зліва, кнопка clear справа |

**Стани полів:**

| Стан | Властивість |
|------|-------------|
| `:hover` | `border-color: --fill-3` |
| `:focus` | `border-color: --acc-bg; box-shadow: 0 0 0 3px --acc-ring` |
| `.is-valid` | `border-color: --ok; box-shadow: 0 0 0 3px --ok-soft` |
| `.is-invalid` | `border-color: --danger; box-shadow: 0 0 0 3px --danger-soft` |

### 11.3 Перемикачі

| Компонент | Клас | Розмір control |
|-----------|------|----------------|
| Checkbox | `.check` | 20×20px, `--r-2` |
| Radio | `.radio` | 20×20px, circle |
| Switch | `.switch` | track 44×26px, thumb 20px |

- **Checkbox checked**: bg `--acc-bg`, галочка SVG з анімацією scale
- **Indeterminate**: bg `--acc-bg`, горизонтальна риска з `mrd-pop` анімацією
- **Switch thumb**: `--switch-thumb` (off) / `--switch-thumb-on` (on)
- **Switch.pending**: track bg `--warn` (стан «вмикається»)

### 11.4 Навігація

| Компонент | Клас | Анімація |
|-----------|------|----------|
| Tabs | `.tabs` | Рухомий індикатор `.tab-ind` (JS-positioned) |
| Breadcrumbs | `.crumbs` | Hover → `--fill-1` bg |
| Pagination | `.pager` | Active page: `--acc-bg` bg, `scale(1.04)` |

### 11.5 Зворотний зв'язок

| Компонент | Клас | Опис |
|-----------|------|------|

### 12.1 Анатомія вікна

**Порядок кнопок**: `[Розгорнути]` — крайня зліва, `[Закрити]` — крайня справа. Кнопки «Згорнути» в декорації **немає** — вона живе в контекстному меню (`Alt+Space` або правий клік).

### 12.2 Стани вікна

|------|------|--------|--------|

| **Maximized** | Без border-radius | — | — |

### 12.3 Кнопки керування

| Кнопка | Normal | Hover |
|--------|--------|-------|
| Maximize | `--fill-1` bg, `--fg-2` color | `--acc-bg` bg, `--acc-fg` color |
| Close | `--fill-1` bg, `--fg-2` color | `--danger` bg, `#fff` color |

### 12.4 Життєвий цикл

| Дія | Анімація | Тривалість |
|-----|----------|-----------|
| **Запуск** | scale від іконки дока → `none` | 420ms |
| **Закриття** | `scale(.94)` + opacity 0 | 200ms |
| **Згортання** | Політ до іконки дока, `scale(.06)` | 420ms |
| **Розгортання/Відновлення** | `left, top, width, height` transition | 320ms |
| **Snap (½ екрана)** | Геометрія transition | 320ms |

### 12.5 Огляд (Overview)

- Шпалери масштабуються `scale(1.06)`, `saturate(.9)`
- Затемнення: overlay `rgba(16,15,14,.40)`
- Вікна масштабуються в сітку (cols = √n)
- Кожне вікно отримує:
  - Hover ring: `inset 0 0 0 3px var(--acc-bg)`
  - Кнопку закриття (`.ov-close`) — `--popover-bg`
  - Підпис (`.ov-label`) — `--popover-bg` pill. Розміщується так, щоб наполовину перекривати нижній край вікна.
- Стрічка робочих областей (`.ws-strip`) зверху
