## 1. Філософія

Meridian побудовано навколо трьох правил, які усувають випадкові рішення й забезпечують передбачуваність інтерфейсу.

### 1.1 Одна форма для всіх контролів

Будь-який інтерактивний елемент — кнопка, поле, чекбокс, пункт меню — має **однаковий border-radius `8px`** (`--r-2`). Коло (`999px`) дозволено лише трьом об'єктам: аватару, перемикачу та значку-індикатору. Проміжних значень немає.

### 1.2 Стан — це шар, а не новий колір

Наведення, натиск і перетягування не вводять нових кольорових токенів. Натомість поверх елемента накладається напівпрозорий шар із `currentColor`:

| Стан | Opacity | Токен |
|------|---------|-------|
| Hover | 8% | `--st-hover: .08` |
| Press / Active | 13% | `--st-press: .13` |
| Drag | 18% | `--st-drag: .18` |

Один механізм працює однаково на будь-якому тлі — світлій кнопці, темному меню чи акцентній заливці.

### 1.3 Рух пояснює, а не прикрашає

Дозволено чотири тривалості й одна основна крива. Анімація інформує про зв'язок елементів (звідки з'явилося, куди зникло), а не «прикрашає». Усі анімації вимикаються за `prefers-reduced-motion`.

### 3.2 Маппінг рампи → семантичні токени

| Токен | Призначення | Light ← ramp[] | Dark ← ramp[] |
|-------|-------------|----------------|---------------|
| `--acc-bg` | Суцільна заливка кнопки | `[3]` | `[3]` |
| `--acc-bg-hover` | Hover суцільної | `[4]` | `[2]` |
| `--acc-fg` | Текст на суцільній заливці | `#ffffff` | `#ffffff` |
| `--acc-text` | Акцентний текст на тлі | `[4]` | `[2]` |
| `--acc-soft` | Тональна підкладка (вибір) | `[0]` (solid) | `rgba([2], .20)` |

> В темній темі `--acc-soft` — це **напівпрозорий** варіант (20% від ac-3), щоб тональна підкладка працювала на темних поверхнях без «вигорання».

### 3.3 Використання

- **`--acc-bg`** → primary-кнопка, бігунок, індикатор вкладки, progress bar
- **`--acc-soft` + `--acc-soft-fg`** → виділений пункт sidebar, активний badge, тональна кнопка
- **`--acc-text`** → текст-посилання, активний label, мітка фокуса поля
- **`--acc-ring`** → `box-shadow: 0 0 0 3px var(--acc-ring)` при `:focus-visible`

## 6. Відступи

Базовий крок — **4px**. Дозволено лише 8 значень:

| Токен | Значення | Застосування |
|-------|----------|-------------|
| `--sp-1` | `4px` | Мінімальний зазор |
| `--sp-2` | `8px` | Gap між іконкою і текстом |
| `--sp-3` | `12px` | Внутрішній відступ toast, banner |
| `--sp-4` | `16px` | Внутрішній відступ картки, padding кнопки |
| `--sp-5` | `24px` | Gap секції, padding панелі |
| `--sp-6` | `32px` | Padding deco-stage |
| `--sp-7` | `48px` | Відступ між секціями документа |
| `--sp-8` | `64px` | Нижній padding документа, margin секції |

> Правило вкладеності: **внутрішній відступ контейнера завжди на один щабель менший за зовнішній.** Проміжні числа заборонені.

### Ключові розміри

| Елемент | Значення |
|---------|----------|
| Висота контрола (btn, input) | `34px` |
| Висота малого контрола | `28px` |
| Висота великого контрола | `42px` |
| Висота панелі вікна | `48px` |
| Висота системної смуги | `34px` |

## 7. Шкала форм

П'ять щаблів border-radius. Радіус визначається **роллю** елемента в ієрархії, а не його розміром:

| Токен | Значення | Роль | Приклади |
|-------|----------|------|----------|
| `--r-1` | `4px` | Мікроелемент | Тег, чип, badge, індикатор |
| `--r-2` | `8px` | **Контрол** | Кнопка, поле вводу, чекбокс, пункт меню |
| `--r-3` | `12px` | Контейнер | Картка, меню, вікно, datepicker |
| `--r-4` | `18px` | Оболонка | Системна панель, док |
| `--r-round` | `999px` | Коло | Аватар, перемикач (switch), badge-pill |

> Між щаблями **немає проміжних значень**. Кожен елемент належить рівно одному щаблю.

## 8. Шари стану

У Rust шар — це `Color::state_layer` із силою `glide_theme::motion::ST_HOVER` / `ST_PRESS` / `ST_DRAG`; у вебконцептах `design/library` — псевдоелемент `::before` з `background: currentColor`:

```css
.layer::before {
  content: ''; position: absolute; inset: 0; z-index: -1;
  background: currentColor; opacity: 0;
  transition: opacity var(--t-1) var(--e-io);
}
.layer:hover::before   { opacity: .08; }  /* --st-hover */
.layer:active::before  { opacity: .13; }  /* --st-press */
```

Цей механізм використовується в:
- `.btn` (усі варіанти)
- `.menu-item`
- `.wctl button` (кнопки вікна)
- `.topbar .tb-btn` (кнопки системної панелі)

## 10. Рух (motion)

Перехід несе рух: зсув, масштаб, розкриття з місця походження або морфінг. Прозорість лише допомагає і завжди коротша за рух — на вході стає повною в перших 40 % руху елемента, на виході зникає лише в останніх 40 % (`glide_theme::motion::assist`). Без доріжки прозорості рух має читатися сам: щонайменше 6px або 6 % масштабу для спливних поверхонь, 24px або 8 % для вмісту сцени. Чиста прозорість дозволена лише шарам стану, заміні растру на місці (колір, гліф), затемненням і розмитому тлу та каретці.

### 10.1 Тривалості

| Токен | Значення | Застосування |
|-------|----------|-------------|
| `--t-1` | `120ms` | Реакція контрола: шар стану, hover |
| `--t-2` | `200ms` | Зміна стану: розкриття меню, зміна кольору |
| `--t-3` | `320ms` | Розкриття: аккордеон, зміна геометрії вікна |
| `--t-4` | `420ms` | Сцена: поява вікна, огляд, launcher |

### 10.2 Криві

| Токен | Значення | Характер |
|-------|----------|----------|
| `--e-out` | `cubic-bezier(.2, 0, 0, 1)` | **Основна**: різкий старт, довгий довід |
| `--e-io` | `cubic-bezier(.4, 0, .2, 1)` | Симетрична: для фонових властивостей |
| `--e-over` | `cubic-bezier(.32, 1.28, .5, 1)` | Легкий **переліт**: перемикачі, масштаб |

### 10.3 Правила застосування

| Властивість | Тривалість | Крива |
|-------------|-----------|-------|
| `opacity` шару стану | `--t-1` | `--e-io` |
| `background`, `color`, `border-color` | `--t-2` | `--e-out` |
| `transform` (scale кнопки) | `--t-1` | `--e-out` |
| `transform` (hover підйом) | `--t-2` | `--e-over` |
| `grid-template-rows` (accordion) | `--t-3` | `--e-out` |
| Геометрія вікна (left, top, width, height) | `--t-3` | `--e-out` |
| Поява/зникнення вікна (transform+opacity) | `--t-4` | `--e-out` / `--e-io` |
| Фонові властивості (theme switch) | `--t-3` | `--e-io` |

## 11. Компоненти

### 11.1 Кнопки (Buttons)

Єдиний клас `.btn` з модифікаторами:

| Модифікатор | background | color | border | Додатково |
|-------------|-----------|-------|--------|-----------|
| *(base)* | `--fill-1` | `--fg-1` | transparent | — |
| `--primary` | `--acc-bg` | `--acc-fg` | — | `box-shadow: --el-1` → `--el-2` on hover |
| `--tonal` | `--acc-soft` | `--acc-soft-fg` | — | — |
| `--outline` | transparent | `--fg-1` | `--line-2` | border → `--fill-3` on hover |
| `--ghost` | transparent | `--fg-2` | — | → `--fg-1` on hover |
| `--danger` | `--danger-soft` | `--danger` | — | → `--danger` bg + `--view-bg` text on hover |

**Розміри:**

| Модифікатор | min-height | padding | font-size |
|-------------|-----------|---------|-----------|
| *(base)* | 34px | `0 16px` | 13.5px |
| `--sm` | 28px | `0 11px` | 12.5px |
| `--lg` | 42px | `0 22px` | 14.5px |
| `--icon` | 34px wide = 34px | `0` | — |

**Зчеплена група** (`.linked`): зовнішні кнопки мають `--r-2`, внутрішні — `--r-1`.

**Сегментований контрол** (`.segmented`): рухома підкладка (`.seg-thumb`) переміщується JS-ом. Активна кнопка отримує фон `--card-bg` з тінню `--el-1`.

### 11.2 Поля вводу (Fields)

| Елемент | Клас | Особливості |
|---------|------|-------------|
| Text input | `.input` | `min-height: 34px`, border `--line-2`, bg `--view-bg` |
| Textarea | `.textarea` | `min-height: 84px`, `resize: vertical` |
| Select | `select.input` | Custom chevron через `background-image` |
| Search | `.searchbar` > `.input` | Іконка зліва, кнопка clear справа |

**Стани полів:**

| Стан | Властивість |
|------|-------------|
| `:hover` | `border-color: --fill-3` |
| `:focus` | `border-color: --acc-bg; box-shadow: 0 0 0 3px --acc-ring` |
| `.is-valid` | `border-color: --ok; box-shadow: 0 0 0 3px --ok-soft` |

### 12.5 Огляд (Overview)

Огляд відкривається на моніторі під курсором і живе лише на ньому: інші монітори показують звичайний стіл і приймають ввід.

- Тло як у лаунчера: шпалера масштабується `scale(1.06)` і переходить у розмиту версію (σ 22 px, `saturate(1.6)`), поверх — скло `--shell-bg`; усе це матеріали, тож з'являються прозорістю за `--e-io`. Однакове тло робить передачу огляд → лаунчер безшовною.
- Сітка показує лише вікна поточного столу на цьому моніторі. Кожен стіл — окрема сторінка своєї сітки; крок сторінок = ширина робочої області − поля сітки − 48 px, тож наступна сторінка починається за 48 px від краю. Кожна неактивна сторінка лежить на картці `--r-4` (`--fill-2`, обвідка `--line-2`), тож сусідні столи завжди видно з країв; їхні вікна — 50 % непрозорості, клік по них перемикає стіл. Перемикання (клік по мініатюрі, колесо, PgUp/PgDn, Ctrl+←/→, Ctrl+1…9) зсуває сторінки за `--t-3` `--e-out`, огляд лишається відкритим; свайп трьома пальцями вбік веде сторінки 1:1 за пальцем (без сусіда — гумка на чверть ходу) і після відпускання доїжджає з його швидкістю (`motion::Release`). Набір символу в огляді (крім h j k l і пробілу) відкриває лаунчер з цим текстом у пошуку.
- Кожне вікно отримує:
  - Hover ring: `inset 0 0 0 3px var(--acc-bg)`
  - Кнопку закриття (`.ov-close`) — `--popover-bg`, лише на наведеній плитці
  - Підпис (`.ov-label`) — `--popover-bg` pill. Розміщується так, щоб наполовину перекривати нижній край вікна.
- Смуга столів (`.ws-strip`) зверху, завжди, навіть з одним столом: живі мініатюри висотою 10 % робочої області (72–120 px) у пропорціях монітора — шпалера, обрізана до `--r-2`, і вікна столу на своїх місцях; проміжок 14 px; під кожною «Стіл N» (`.t-cap`, `--fg-3`, активний 600 `--fg-1`). Активну обводить кільце 2 px `--acc-text` за 3 px від краю, що переїжджає між мініатюрами за `--t-3` `--e-out`. Наведення — підйом 2 px `--e-over` і обвідка `strip-pick`. Мініатюру можна перетягнути вздовж смуги (поріг 6 px): вона йде за курсором поверх інших, сусіди розступаються за `--t-2` `--e-out`, відпускання ставить стіл на нове місце, а мініатюра доїжджає туди з точки відпускання. У динамічному режимі в кінці плитка «+» 56 px (`--fill-2`, `--line-2`), що на час перетягування розкривається до ширини мініатюри з підписом «Новий стіл».
- Відкриття: плитки морфують з місць вікон у слоти, смуга виїжджає з-під топбара на 24 px; прозорість лише `min(1, p / 0.4)`.
- Перетягування вікна: натискання без руху на 6 px — клік (вихід на вікні). Далі плитка стискається до 240 px завширшки від точки хвату (`--t-2` `--e-out`) і йде за курсором; цілі — мініатюра столу (scale 1.08 `--e-over`, кільце 2 px `--acc-bg`, шар `--acc-bg` 18 %; плитка ще × 0.8), «+» (новий стіл) і 64 px біля лівого / правого краю (400 мс затримки перемикають сторінку; скидання кладе вікно на сусідній стіл, після останнього — на новий). Скинуте на інший стіл вікно летить у своє місце в мініатюрі (`--t-3` `--e-out`, радіус `--r-3` → 2 px); скинуте на свій стіл або повз ціль, чи після Esc, повертається в слот. Shift+←/→ перекидає наведене вікно на сусідній стіл. Стіл, що спорожнів, лишається, доки огляд не закриється.

#### Автоприховування (smart)

`[dock] autohide = "smart" | "always" | "never"`, типово `smart`.

- **smart**: док видимий, доки жодне вікно поточного робочого простору не
  перекриває його зону (прямокутник оболонки + `--sp-3` навколо). Щойно
  вікно (розгорнуте, повноекранне або просто підсунуте) заходить у зону —
  док ховається. Коли зона знову вільна — повертається.
- **always**: док схований завжди, поки не викликаний.
- **never**: док не ховається (крім огляду й лаунчера, як зараз).

Виклик схованого дока: курсор упирається в нижній край екрана (`y ≥ bottom − 1`)
і тримається там 120ms (`--t-1`); з клавіатури — `Super+D`. Док лишається
видимим, доки курсор у зоні дока (+`--sp-4` ореол), і ховається через 400ms
після виходу курсора. Док **ніколи** не ховається, поки відкрите його меню,
йде перетягування, тримається кнопка або показується тултіп. Новий запущений
застосунок або `attention` показують док на 1.5с. У сховованому стані док не
резервує місця: вікна користуються всією робочою зоною.

| Перехід | Рух |
|---------|-----|
| Ховання | `translateY(100% + 12px)` + opacity 1→0, `--t-3` `--e-io` |
| Показ | зворотний, `--t-2` `--e-out` |
| Реверс посередині | продовжується з поточної позиції, без стрибка |

## 17. Оболонка Glide: спільні правила компонентів

Ці правила зобов'язують кожен модуль оболонки (topbar, dock, launcher, overview,
toast, декорації) виглядати як одна система. Модуль не може вводити власні
значення там, де тут є правило.

### 17.1 Родина «popover»

Усі спливні поверхні — меню (topbar, dock, launcher, вікно), quick settings,
центр сповіщень, медіаплеєр, tooltip, toast:

| Властивість | Значення |
|-------------|----------|
| Тло | `--popover-bg` |
| Обвідка | 1px `--line` (усередині) |
| Радіус | `--r-3`; tooltip — `--r-2` |
| Тінь | `--el-3`; tooltip — `--el-2` |
| Відступ від якоря | `--sp-2` (8px) |
| Внутрішній відступ панелі | `--sp-3` (12px) |
| Меню: padding контейнера / висота рядка / радіус рядка | `--sp-1` / 34px / `--r-2` |
| Заголовок меню | `.t-cap`, `--fg-3`, роздільник 1px `--line` |
| Підсвічений рядок | `--fill-2` |

### 17.2 Поява і зникнення

| Поверхня | Поява | Зникнення |
|----------|-------|-----------|
| Меню, popover, QS, NC, медіаплеєр | `--t-2` `--e-out`: opacity 0→1, зсув 6px від якоря →0, scale .94→1 | `--t-2` `--e-io`, у зворотному напрямку |
| Tooltip | `--t-1` opacity | `--t-1` opacity |
| Toast | `--t-4` `--e-out`: зсув з краю + opacity | `--t-2` `--e-io`: opacity + scale .96 |
| Snap-прев'ю | `--t-2` `--e-out`: scale .92→1, opacity min(1, p/.4) | `--t-2` `--e-out`: scale 1→.92, opacity min(1, p/.4) |

Перехід **оборотний**: закриття під час появи продовжує з поточного прогресу,
а не стрибає. Кадри малюються, доки будь-який перехід не завершився.

### 17.3 Стани контролів

| Стан | Реалізація | Рух |
|------|------------|-----|
| Hover | шар `currentColor` 8% (`--st-hover`) | opacity `--t-1` `--e-io`, crossfade між сусідніми елементами (без «спалаху» з нуля) |
| Press | шар 13% (`--st-press`), доки кнопка утримується | миттєво увімк., `--t-1` вимк. |
| Open / Active | `--fill-2` тло, текст `--fg-1` | `--t-2` `--e-out` |
| Focus (клавіатура) | кільце 2px `--acc-bg` зовні, радіус елемента + 2 | `--t-1` opacity |
| Disabled | текст `--fg-4` | — |

Текст контролу в спокої — `--fg-2`, при hover/open/active — `--fg-1`.

### 17.4 Мікроелементи

| Елемент | Правило | Рух |
|---------|---------|-----|
| Switch (малий 28×16 у смузі, великий 44×26 у панелях) | track `--fill-3` → `--acc-bg`; thumb `--switch-thumb` → білий | thumb `--t-2` `--e-over`, track colour `--t-2` `--e-out` |
| Slider | доріжка 6px `--fill-2`, заливка `--acc-bg`, ручка 14px | під час перетягування миттєво; програмна зміна `--t-2` `--e-out` |
| Badge-лічильник | pill `--acc-bg`, `.t-micro` | поява scale .6→1 `--t-2` `--e-over`, зникнення `--t-1` |
| Індикатор запуску (dock) | 4px крапка → 16px риска | ширина `--t-3` `--e-out`; поява/зникнення opacity `--t-2` |
| Сегментований контрол | активний сегмент `--fill-3`, текст `--fg-1` | підкладка ковзає `--t-2` `--e-out` |

### 17.5 Типографіка оболонки

| Роль | Стиль |
|------|-------|
| Підпис контролу у смузі | `TOPBAR` (12.5/16, 520) |
| Назва у панелі (tile, рядок) | `HEAD` |
| Підпис під назвою | `CAP`, `--fg-3` |
| Заголовок секції | `MICRO`, `--fg-3` (єдиний uppercase) |
| Пункт меню | `MENU_ITEM` |
| Підпис іконки лаунчера | `LAUNCHER_CAPTION` |

Другорядний текст завжди `--fg-2` (0.66/0.68), третинний — `--fg-3` (0.44/0.46). Власні альфи (0.72, 0.55 …) заборонені.

## 18. Вікно блокування та Display Manager

Вікно блокування (Lock Screen) та системний екран входу (Display Manager / DM) підпорядковуються спільній візуальній мові оболонки Glide та базовим правилам Meridian. Вони реалізують спокійну, передбачувану геометрію без випадкових округлень.

### 18.1 Розмежування режимів

| Режим | Ціль | Особливості інтерфейсу |
|-------|------|------------------------|
| **Lock Screen** | Захист поточної робочої сесії | Сесія зафіксована (вибір стільниці прихований). Показується поточний заблокований користувач. Активне відтворення медіа транслюється у віджет під годинником або Status Island у смузі. |
| **Display Manager** | Первинний вхід у систему (greetd) | Дозволяє перемикання користувачів (`UserEntry`). У правому нижньому куті відображається вибір Wayland-сесії (`SessionEntry`: Glide, Sway, GNOME). |

### 18.2 Форма та радіуси (Правило 1.1)

- **Жодних капсульних кнопок (`999px`)**: Усі кнопки (кнопки статусу, вибору розкладки, полиці живлення, вибору сесії, кнопки підтвердження дій) мають суворий радіус **`--r-2` (8px)**.
- **Радіус `--r-round` (999px)** дозволено **виключно аватару користувача** (діаметр 84px).
- Внутрішні елементи (кнопка підтвердження в полі пароля, кнопки дій усередині полиці живлення) використовують радіус **`--r-1` (4px)** згідно з правилом вкладеності.
- Контейнери (меню сесії, розширений віджет медіа) використовують **`--r-3` (12px)**.

### 18.3 Інтеграція з системною смугою (Topbar)

Верхня межа екрана оформлена як напівпрозора системна смуга Glide (`--shell-bg` + `blur(20px) saturate(1.6)`):
- **Зліва**: Статус блокування (`Заблоковано` з піктограмою замка) або системний бренд у режимі DM.
- **По центру**: Status Island — у компактному стані відображає поточний статус, а при активному відтворенні медіа — мікроеквалайзер та назву композиції.
- **Справа**: Кластер системних статусів (прямокутні кнопки `--r-2`):
  - Перемикач розкладки клавіатури: моноширинний текст (`UA` / `EN`, шрифт `JetBrains Mono`).
  - Піктограма мережі (Wi-Fi).
  - Рівень заряду батареї з моноширинним відсотком (`NN%`).

### 18.4 Центр аутентифікації

- **Монументальний кінематографічний годинник**: Розмір 136–144px (за зразком macOS Sequoia «Show Large Clock» та Android 14/15 «Giant Clock»), вага 580–620, щільний від'ємний трекінг `-0.05em`, суворі табличні цифри (`tabular-nums`), дифузна об'ємна тінь глибини над шпалерами. Над годинником розташовується дата з мікробейджем дня тижня.
- **Hero-аватар з багатошаровим скляним п'єдесталом**: Збільшений розмір 104–112px (коло `--r-round`). Обіграний потрійним шаром: зовнішній світловий ореол (Ambient Halo) на наведенні/фокусі, напівпрозоре скляне кільце (Glass Pedestal) з тінню `--el-2`, внутрішній градієнтний диск з великою виразною літерою (40–42px, 680 вага) та міні-бейдж безпеки сесії в правому нижньому кутку.
- **Поле введення пароля**: Ширина 260px, висота 40–42px, радіус `--r-2` (8px). Тло `--sunken-bg`, обвідка `--line-2`, кільце фокуса `0 0 0 3px var(--acc-ring)`. При фокусі ореол аватара м'яко активується в унісон.
- **Помилка введення**: Шейк-анімація (320ms, крива `--e-out`), обвідка `--danger`, підсвічування `0 0 0 3px var(--danger-soft)`.
- **Підказка стану**: Індикатор біометрії (Touch ID), Caps Lock або системні повідомлення PAM шрифтом `.t-call`.

### 18.5 Двоетапне керування живленням (Power Inline Arming)

Полиця живлення розташована в лівому нижньому куті:
- Контейнер висотою 40px з радіусом `--r-2` (8px) на тлі `--shell-bg`.
- Кнопки дій: **Сон**, **Перезапуск**, **Вимкнути** (радіус `--r-1`, шари стану 8% hover, 13% press).
- Натискання переводить блок у стан озброєння (200ms, `--e-out`): з'являється запитання, кнопка підтвердження (`--danger` для перезапуску/вимкнення, `--acc-bg` для сну) та кнопка скасування. Скасування також спрацьовує за клавішею `Esc`.
